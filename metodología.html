Análisis Exploratorio de Datos - Diabetes

4 Metodología

El análisis se desarrolla en las siguientes etapas:

  1. Carga y preparación de datos: se importa el dataset diabetes.csv (ver chunk de configuración en index.Rmd), definiendo la variable respuesta (Diabetes), las variables numéricas (IMC, SaludM, SaludF) y las variables categóricas (18 indicadores de salud, hábitos y sociodemográficos).
  2. Análisis univariado (sección siguiente): construcción de tablas de frecuencia/estadísticos descriptivos y gráficos (barras, pastel, lollipop, histograma, boxplot) para cada variable.
  3. Análisis bivariado (capítulo 02-bivariado.Rmd): comparación de cada variable frente a Diabetes mediante gráficos comparativos y pruebas estadísticas (Anderson-Darling, Levene, Mann-Whitney para variables numéricas; chi-cuadrado para variables categóricas).
  4. Interpretación y conclusiones: síntesis de los hallazgos más relevantes para orientar hipótesis de trabajo en un eventual modelo predictivo de diabetes.

Todas las visualizaciones se generaron con ggplot2 en R, siguiendo buenas prácticas de diseño (paletas perceptualmente uniformes como viridis, etiquetas descriptivas y títulos informativos, y escalas consistentes entre gráficos comparables).
